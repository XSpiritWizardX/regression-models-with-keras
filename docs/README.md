# Multilingual Documentation

Project documentation is maintained in three languages.

- [English](project-guide.en.md)
- [한국어 / Korean](project-guide.ko.md)
- [日本語 / Japanese](project-guide.ja.md)

Each guide follows the same structure and covers:

- project purpose and dataset
- TensorFlow/Keras model architecture
- repository structure and local usage
- AI-assisted / agentic SDLC workflow
- quality gates and review responsibilities
- ML methodology and known limitations
- testing, documentation, and future improvement goals

The English version is the reference version for technical terminology. Korean and Japanese documentation should be updated in the same pull request whenever the reference guide changes materially.
